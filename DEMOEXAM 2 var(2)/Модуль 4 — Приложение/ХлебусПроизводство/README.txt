Информационная система производства ООО «Хлебус»
=================================================

Настольное приложение для учёта производственных данных хлебозавода:
заказы с расчётной стоимостью материалов и справочник продукции.
Вход в систему защищён логином, паролем и капчей-пазлом; после трёх
неверных попыток учётная запись блокируется.

Требования
----------
- Python 3.8 или новее.
- Библиотека tkinter. Она входит в стандартную поставку Python для
  Windows и macOS. В Linux при необходимости устанавливается пакетом
  python3-tk (например: sudo apt install python3-tk).
- Сторонние библиотеки НЕ требуются — приложение использует только
  стандартную библиотеку Python (tkinter, sqlite3, hashlib).

Запуск
------
1. Откройте папку проекта в терминале.
2. Выполните команду:

       python main.py

   (в Windows может потребоваться команда py main.py)

База данных hlebus.db уже подготовлена и лежит рядом с main.py, поэтому
дополнительная настройка не нужна.

Учётные записи для проверки
---------------------------
Администратор:  логин admin    пароль admin123
Пользователь:   логин user     пароль user123
Пользователь:   логин kassir   пароль kassir2025

Администратору доступно управление учётными записями (добавление,
изменение, снятие блокировки) и просмотр производственных данных.
Пользователю доступен только просмотр заказов и продукции.

Если случайно заблокировали учётную запись при проверке капчи или
пароля, войдите администратором и снимите блокировку на вкладке
«Пользователи» кнопкой «Снять блокировку».

Структура проекта
-----------------
main.py                  — точка входа, переключение экранов
hlebus.db                — база данных SQLite с демонстрационными данными
app/config.py            — параметры и тексты сообщений
app/models/              — сущности предметной области (пользователь, роль, заказ)
app/database/            — подключение к БД и репозитории
app/services/            — бизнес-логика: хеширование пароля, авторизация, капча
app/ui/                  — окна и визуальные компоненты
app/assets/              — изображение для капчи
tests/test_logic.py      — модульные тесты бизнес-логики

Проверка тестами
----------------
Из папки проекта:

       python -m unittest discover -s tests -v
