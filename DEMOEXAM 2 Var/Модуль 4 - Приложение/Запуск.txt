Информационная система авторизации
Заказчик: Молочный комбинат «Полесье»

Структура проекта:
   main.py                      - точка входа
   config.py                    - общие настройки и название приложения
   models/user.py               - класс сущности "Пользователь"
   database/connection.py       - подключение к MS SQL Server
   database/user_repository.py  - запросы к таблице "Пользователи"
   components/captcha_widget.py - интерактивная капча (пазл)
   forms/login_form.py          - форма авторизации
   forms/admin_form.py          - панель администратора
   forms/user_desktop_form.py   - рабочий стол пользователя
   forms/user_dialog.py         - добавление и изменение пользователя

Запуск:
   1. pip install -r requirements.txt
   2. В файле database/connection.py указать имя своего сервера (SERVER).
   3. Развернуть базу скриптом "Модуль 2 - База данных.sql".
   4. python main.py

Тестовые учётные записи:
   Администратор - логин admin, пароль admin
   Пользователь - логин user,  пароль user

Порядок входа:
   - ввести логин и пароль;
   - собрать изображение (пазл): нажать на два фрагмента, чтобы поменять
     их местами, и расставить их по порядку 1..9;
   - нажать "Войти".
